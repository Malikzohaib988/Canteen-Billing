# Campus Canteen Billing System

A beginner Python billing program for a fictional campus canteen.

## Features

- Four menu choices
- Multiple orders in one bill
- Quantity and subtotal calculations
- 10% discount on bills of PKR 1,000 or more

## How to run

```
py billing.py
```

## Menu

| Choice | Item      | Price    |
|--------|-----------|----------|
| 1      | Tea       | Rs 80    |
| 2      | Sandwich  | Rs 250   |
| 3      | Juice     | Rs 150   |
| 4      | Coffee    | Rs 180   |
| 0      | Checkout  | —        |

## Discount rule

A 10% discount is applied automatically when the subtotal is PKR 1,000 or more.

## Concepts

Variables, input/output, operators, conditions and loops.
